# Glassify Shop

Premium glassmorphism e-commerce frontend designed to be published directly on GitHub Pages.

## Files
All files are intentionally kept in the repository root. No subfolders are required.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload every file from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the deployment.

## Notes
This is a frontend/demo storefront. The cart uses browser localStorage. Real Shopify products, checkout, payments, orders and customer accounts require Shopify integration/backend.
